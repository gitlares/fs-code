# FS Code 0.1.6 Alpha

Native macOS 15+ editor for Apple Silicon. Developer ID signed and notarized by Apple.

## Changes

- Adds project-scoped Code Intelligence as an explicit permission alongside Terminal and Computer Use.
- Adds Swift symbol definition and reference lookups through `sourcekit-lsp`, gated by the Code Intelligence capability.
- Adds structural code search through `ast-grep` when available, with a clear fallback message when the binary is missing.
- Uses `rg` for project text search when available, with the existing deterministic scan as fallback.
- Audits file writes produced by approved development commands and imports those changes into the agent change journal when possible.
- Fixes idle shutdown and relaunch of the Swift symbol server so a later lookup starts a fresh `sourcekit-lsp` session.
- Bumps the app to version 0.1.6 / build 7 for the Sparkle update channel.

## Installation and updates

Download the arm64 ZIP, extract FS Code.app, and replace the copy in Applications after quitting FS Code. Existing 0.1.1 and newer alpha installations can use FS Code -> Check for Updates.... Automatic checks and installation remain disabled by default.

## Validation and limits

Validation for this release includes the full Swift test suite: 234 XCTest tests with 3 environment-dependent tests skipped, plus 33 Swift Testing tests, all passing. Release validation also includes Developer ID signature verification, Apple notarization/stapling checks, Gatekeeper assessment, remote download checksum verification, and Sparkle Ed25519 signature verification.

This remains an alpha. Agent shell commands may still create changes that cannot be fully audited, especially deletions, very large files, binary files, or projects beyond the snapshot budget. Enable project capabilities deliberately and review changes. Connected AI requests send supplied context and tool results to the chosen provider. No product analytics collector is included. Intel binaries are not included.
