# FS Code 0.1.1 Alpha

Native macOS 15+ editor for Apple Silicon. Developer ID signed and notarized by Apple.

## Changes

- Native application colors and improved chat scrolling and layout.
- Base16/Base24 YAML themes for editor and terminal, with separate light/dark selections in Settings. Built-in Dracula and Alucard retain their colors.
- Project-scoped capability controls and agent development tools, including command execution and optional macOS accessibility operations.
- Automatic RTK wrapping for compatible commands when RTK is installed.
- Improved conversation usage reporting and collapsible task details.
- Sparkle update feed and Ed25519-signed update archive.

## Installation and updates

Download the arm64 ZIP, extract FS Code.app, and replace the copy in Applications after quitting FS Code. Version 0.1.0 needs this manual upgrade once because its update feed was disabled. Starting with this version, use FS Code → Check for Updates…. Automatic checks and installation remain disabled by default.

## Validation and limits

205 XCTest tests (2 optional screenshot tests skipped) and 33 Swift Testing tests, with zero failures. Theme import and native appearance were checked in a real application window. An installed-version-to-version Sparkle upgrade has not yet been exercised.

This remains an alpha. Agent shell commands may change files outside the audited edit-tool restore flow. Enable project capabilities deliberately and review changes. Connected AI requests send supplied context and tool results to the chosen provider. No product analytics collector is included. Intel binaries are not included.
