# FS Code 0.1.3 Alpha

Native macOS 15+ editor for Apple Silicon. Developer ID signed and notarized by Apple.

## Changes

- Repairs persisted native-agent histories that contain an interrupted tool call followed by later user messages, moving the synthetic interruption result back beside its tool call so the next provider request stays valid.
- Rechecks repaired history when resuming a thread and before starting a new turn, preventing stale in-memory history from surfacing as a malformed provider request.
- Reports safe, specific categories for direct transport failures and malformed history errors without exposing provider bodies, internal tool IDs, or credential-adjacent details.
- Bumps the app to version 0.1.3 / build 4 for the Sparkle update channel.

## Installation and updates

Download the arm64 ZIP, extract FS Code.app, and replace the copy in Applications after quitting FS Code. Existing 0.1.1 and 0.1.2 alpha installations can use FS Code → Check for Updates…. Automatic checks and installation remain disabled by default.

## Validation and limits

211 XCTest tests (2 optional screenshot tests skipped) and 33 Swift Testing tests passed with zero failures. Release validation also includes `git diff --check`, Developer ID signature verification, Apple notarization/stapling checks, Gatekeeper assessment, launch testing, and SHA-256 checksum verification of the published ZIP.

This remains an alpha. Agent shell commands may change files outside the audited edit-tool restore flow. Enable project capabilities deliberately and review changes. Connected AI requests send supplied context and tool results to the chosen provider. No product analytics collector is included. Intel binaries are not included.
