# FS Code 0.1.10 Alpha

This alpha improves project permissions, queued-message feedback, and text-file attachments.

## What changed

- Redesigns the project Permissions view with native switches, grouped capabilities, clearer descriptions, and visible Accessibility status.
- Shows the actual provider failure when a queued conversation pauses, while removing stale queue banners when no messages remain.
- Raises external UTF-8 text attachment limits to 1 MB per file and 4 MB per chat, with up to 8 attachments.

## Validation

- `swift test --build-system native`: passed. Optional visual-preview and ast-grep checks remain skipped when their opt-in dependency or environment flag is absent.
- `git diff --check`: passed.

## Installation and updates

Download the arm64 ZIP, extract `FS Code.app`, and replace the copy in Applications after quitting FS Code. Existing alpha installations can use **FS Code → Check for Updates...** once the Sparkle feed refreshes.

## Notes

This remains an alpha build. Review agent-edited files before committing or publishing project work.
