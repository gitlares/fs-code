# FS Code 0.1.9 Alpha

This alpha improves the assistant composer, project memory, and terminal text input for international keyboards.

## What changed

- Adds separate project permissions for secrets/environment files and network-reaching commands, while keeping local build and test commands available independently.
- Adds shared project memory tools so agents can read and maintain durable project facts across models and accounts.
- Adds an `@file` mention palette in the chat composer with keyboard navigation and live filtering.
- Adds a `/` composer shortcut for mode, model, effort, account, stats, clear-chat, and help actions.
- Shows memory size in the context stats menu when project memory is present.
- Refreshes chat activity and modified-file summaries as compact terminal-style chips with status icons.
- Improves assistant list formatting and turn separation in the transcript.
- Lets the integrated terminal type Option-modified characters such as `@` on Spanish and Latin American keyboard layouts.

## Validation

- `swift test --build-system native`: passed. Optional visual-preview and ast-grep checks remain skipped when their opt-in dependency or environment flag is absent.
- `git diff --check`: passed.

## Installation and updates

Download the arm64 ZIP, extract `FS Code.app`, and replace the copy in Applications after quitting FS Code. Existing alpha installations can use **FS Code → Check for Updates...** once the Sparkle feed refreshes.

## Notes

This remains an alpha build. Review agent-edited files before committing or publishing project work.
