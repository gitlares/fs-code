# FS Code 0.1.5 Alpha

Native macOS 15+ editor for Apple Silicon. Developer ID signed and notarized by Apple.

## Changes

- Refines the native macOS chrome across the editor, assistant, TODOs, terminal, Markdown preview, and system prompt views.
- Replaces duplicated tab-strip implementations with a shared native tab strip used by editor files and assistant conversations.
- Adds shared UI helpers for icon-only buttons, spacing, radius, and text styling so touched views stay more consistent.
- Updates the assistant composer immediately after send events so the input state tracks the conversation without waiting for the debounced full refresh.
- Keeps release channel metadata current by bumping the app to version 0.1.5 / build 6.

## Installation and updates

Download the arm64 ZIP, extract FS Code.app, and replace the copy in Applications after quitting FS Code. Existing 0.1.1 and newer alpha installations can use FS Code -> Check for Updates.... Automatic checks and installation remain disabled by default.

## Validation and limits

Validation for this release includes the full Swift test suite: 216 XCTest tests with 2 optional screenshot tests skipped, plus 33 Swift Testing tests, all passing. Release validation also includes Developer ID signature verification, Apple notarization/stapling checks, Gatekeeper assessment, remote download checksum verification, and Sparkle Ed25519 signature verification.

This remains an alpha. Agent shell commands may change files outside the audited edit-tool restore flow. Enable project capabilities deliberately and review changes. Connected AI requests send supplied context and tool results to the chosen provider. No product analytics collector is included. Intel binaries are not included.
