# FS Code 0.1.8 Alpha

This alpha improves the native workspace interactions and makes the local agent runtime more reliable when RTK is installed.

## What changed

- Adds native file-tree context actions for creating, copying, moving, renaming, duplicating, revealing, and sending files to Trash.
- Lets users drop file paths into the integrated terminal with shell-safe quoting.
- Shows input, output, cache, and total token values when the provider reports them.
- Keeps the chat's transient thinking indicator from remaining below streamed assistant commentary or a final answer.
- Ensures RTK can invoke the resolved Homebrew `rg` binary even when a GUI-launched application has a limited `PATH`.

## Validation

- `swift test --build-system native`: passed after the RTK and chat-transcript regressions were corrected. Optional visual-preview and ast-grep checks remain skipped when their opt-in dependency or environment flag is absent.
- `git diff --check`: passed.

## Installation and updates

Download the arm64 ZIP, extract `FS Code.app`, and replace the copy in Applications after quitting FS Code. Existing alpha installations can use **FS Code → Check for Updates...** once the Sparkle feed refreshes.

## Notes

This remains an alpha build. Review agent-edited files before committing or publishing project work.
