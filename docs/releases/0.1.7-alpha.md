# FS Code 0.1.7 Alpha

This alpha release improves native agent runtime context handling and syncs the vendored AgentRunKit snapshot used by FS Code.

## What changed

- Uses the provider catalog maximum context window when available, instead of showing a smaller fallback window.
- Adds proactive context compaction in the native agent runtime before a conversation grows past its configured context threshold.
- Persists compacted conversation history and emits a context-compacted event so the UI can represent that the history was rewritten intentionally.
- Syncs the vendored AgentRunKit snapshot to 6.1.0, including text-to-speech stitching and loudness updates.
- Keeps FS Code local AgentRunKit context compactor visibility patch documented in the vendored upstream notes.
- Updates the release version to 0.1.7 alpha, build 8.

## Validation

- `swift test --build-system native`: 236 XCTest tests passed, 3 skipped; 33 Swift Testing tests passed.

## Installation and updates

Download the arm64 ZIP, extract `FS Code.app`, and replace the copy in Applications after quitting FS Code. Existing alpha installations can use **FS Code → Check for Updates...** once the Sparkle feed refreshes.

This remains an alpha build. Review agent-edited files before committing or publishing project work.
