# FS Code 0.1.2 Alpha

Native macOS 15+ editor for Apple Silicon. Developer ID signed and notarized by Apple.

## Changes

- Development commands can now be launched by bare executable name, resolving against safe absolute PATH entries and fixed system fallbacks instead of requiring an absolute path.
- Command launch failures now report a safe system diagnostic in agent tool output, including the executable and errno, instead of a generic failure message.
- Project-local executable paths are not searched implicitly, including through PATH symlinks into the project root.
- The workspace sidebar now uses the same rectangular split-pane treatment as the assistant panel.

## Installation and updates

Download the arm64 ZIP, extract FS Code.app, and replace the copy in Applications after quitting FS Code. Existing 0.1.1 alpha installations can use FS Code → Check for Updates…. Automatic checks and installation remain disabled by default.

## Validation and limits

208 XCTest tests (2 optional screenshot tests skipped) and 33 Swift Testing tests passed with zero failures. Bare Git status, diff, commit and push to a local test remote are covered. Project context loading was checked: active project rules are reloaded for each normal chat turn; an ongoing turn retains its initial context. This remains an alpha. Agent shell commands may change files outside the audited edit-tool restore flow. Enable project capabilities deliberately and review changes. Connected AI requests send supplied context and tool results to the chosen provider. No product analytics collector is included. Intel binaries are not included.
