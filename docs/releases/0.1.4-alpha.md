# FS Code 0.1.4 Alpha

Native macOS 15+ editor for Apple Silicon. Developer ID signed and notarized by Apple.

## Changes

- Shows provider rate limits as an explicit, actionable message instead of a generic response failure.
- Pauses queued assistant messages with a rate-limit reason so the next action is clearer.
- Requests macOS Accessibility permission through the project permissions flow before Computer Use runs, and blocks the pending action until the user retries after granting access.
- Adds close and quit diagnostics around workspace shutdown while the remaining quit issue is investigated.
- Bumps the app to version 0.1.4 / build 5 for the Sparkle update channel.

## Installation and updates

Download the arm64 ZIP, extract FS Code.app, and replace the copy in Applications after quitting FS Code. Existing 0.1.1, 0.1.2, and 0.1.3 alpha installations can use FS Code -> Check for Updates.... Automatic checks and installation remain disabled by default.

## Validation and limits

Validation for this release includes the full Swift test suite: 216 XCTest tests with 2 optional screenshot tests skipped, plus 33 Swift Testing tests, all passing. Release validation also includes Developer ID signature verification, Apple notarization/stapling checks, Gatekeeper assessment, and SHA-256 checksum verification of the published ZIP.

This remains an alpha. Agent shell commands may change files outside the audited edit-tool restore flow. Enable project capabilities deliberately and review changes. Connected AI requests send supplied context and tool results to the chosen provider. No product analytics collector is included. Intel binaries are not included.
